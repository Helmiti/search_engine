# search_engine

Локальный консольный поисковый движок на C++ для поиска по текстовым документам.

Проект выполнен в рамках финальной работы курса «Разработчик на C++ с нуля».

## Возможности

- Загрузка настроек и списка документов из `config.json`.
- Чтение запросов из `requests.json`.
- Построение инвертированного индекса с частотами слов по документам.
- Многопоточная индексация документов.
- Поиск документов, содержащих все уникальные слова запроса.
- Расчёт относительной релевантности и сортировка результатов по убыванию рейтинга.
- Ограничение количества результатов параметром `max_responses`.
- Запись результатов в `answers.json`.
- Автоматические тесты с CTest; при подключении Google Test — дополнительные модульные тесты.

## Технологии

- C++17 и стандартная библиотека C++
- CMake (3.16+)
- Qt Creator или другая IDE с поддержкой CMake
- Компилятор MinGW/GCC либо совместимый компилятор C++17
- CTest и Google Test (дополнительно)

Для формата JSON в проект включены собственные классы `MiniJSON`. Библиотеки Qt для сборки не требуются.

## Сборка и запуск в Qt Creator

1. Откройте `CMakeLists.txt` через **Файл → Открыть файл или проект**.
2. Выберите комплект сборки (например, Desktop Qt / MinGW 64-bit).
3. Убедитесь, что `ENABLE_GOOGLE_TEST` имеет значение `OFF`, если Google Test не установлен.
4. Соберите проект с помощью **Ctrl+B**.
5. В **Проекты → Настройки запуска** укажите **рабочий каталог** — корневую папку проекта, содержащую `config.json`.
6. Запустите `search_engine` кнопкой **Запуск**.

Если рабочий каталог установить невозможно, можно передать путь к корню проекта первым аргументом командной строки.

## Сборка из терминала

Из корня проекта:

```sh
cmake -S . -B build -DBUILD_TESTING=ON -DENABLE_GOOGLE_TEST=OFF
cmake --build build
```

Запускайте собранный `search_engine` из корня проекта либо передавайте абсолютный путь к корню проекта первым аргументом.

Проверка базовых тестов:

```sh
ctest --test-dir build --output-on-failure
```

## Google Test

Google Test не скачивается автоматически при настройке проекта. Для локального подключения:

1. Получите исходный код Google Test из официального репозитория: https://github.com/google/googletest
2. Поместите его в `third_party/googletest`, чтобы файл `third_party/googletest/CMakeLists.txt` существовал.
3. Включите `ENABLE_GOOGLE_TEST=ON` и пересоберите проект.

Пример:

```sh
cmake -S . -B build -DBUILD_TESTING=ON -DENABLE_GOOGLE_TEST=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

Тесты Google Test расположены в `tests/test_gtest.cpp`, автономные тесты — в `tests/test_offline.cpp`.

## Формат входных файлов

`config.json`:

```json
{
  "config": {
    "name": "ITBoxSearchEngine",
    "version": "0.1",
    "max_responses": 5
  },
  "files": [
    "resources/file001.txt",
    "resources/file002.txt"
  ]
}
```

`requests.json`:

```json
{
  "requests": [
    "milk water",
    "sugar"
  ]
}
```

`answers.json` создаётся автоматически и содержит ответы в объекте `answers`, например:

```json
{
  "answers": {
    "request001": {
      "result": "true",
      "relevance": [
        {"docid": 0, "rank": 1.0}
      ]
    },
    "request002": {
      "result": "false"
    }
  }
}
```

Реальные результаты зависят от текстов, указанных в `config.json`.

## Принцип ранжирования

Поисковый запрос разбивается на уникальные слова. В выдачу попадают документы, содержащие **все** эти слова. Абсолютная релевантность документа равна сумме частот искомых слов в нём. Относительная релевантность равна отношению этой суммы к максимальной абсолютной релевантности среди найденных документов. Результаты выдаются по убыванию рейтинга.
